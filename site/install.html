Install and updates

One binary, one command. You need Claude Code 2.1.234 or later (2.1.224 on macOS and Linux) and git. Claude Code 2.1.287 or later adds the Imperatorium mod.

Install

The script downloads the binary for your machine from the latest release, checks its SHA-256 against the release's signed manifest, and runs imperatorium install.

# Windows (PowerShell)
irm https://github.com/hypertetrahedron/imperatorium/releases/latest/download/install.ps1 | iex

# Windows, when PowerShell's policy blocks that (cmd.exe)
curl -fsSLo install.cmd https://github.com/hypertetrahedron/imperatorium/releases/latest/download/install.cmd && install.cmd

# Linux / macOS
curl -fsSL https://github.com/hypertetrahedron/imperatorium/releases/latest/download/install.sh | sh

Prefer to read it first? Each script is short. Download it, read it, then run it with --dry-run to see what would change without changing anything. Set IMPERATORIUM_CHANNEL=preview for the preview channel.

imperatorium install asks where your projects live and which extras you want (dictation, Stream Deck, auto-approval, the mod, phone push, the hotkey, start at logon). It writes your config, adds its hooks to ~/.claude/settings.json (backing it up first), and registers a service that keeps the dispatcher running: scheduled tasks on Windows, a systemd user unit on Linux, a launchd agent on macOS. Every step can be run again safely. Restart running Claude Code sessions afterwards so they pick up the hooks, then open the window:

imperatorium open

The Windows and Linux builds are supported; macOS builds are built by CI but not yet tested on a Mac. The onboarding guide walks through the whole thing step by step, including other machines.

Day to day

imperatorium check                  # what is present and missing; changes nothing
imperatorium status                 # is everything running
imperatorium restart                # all, or one of dispatcher | streamdeck | hotkey
imperatorium update                 # the latest release on your channel
imperatorium update --rollback      # back to the binary before the last update
imperatorium uninstall              # hooks, mod and service; config and state stay
imperatorium uninstall --purge      # ...and the config and state too

Releases you can trust

  • Every published build is made by CI from a tag; nothing built on a developer's machine is distributed.
  • Each release's manifest carries an Ed25519 signature that the binary checks before it updates, and the binary's SHA-256 is checked against it.
  • Windows binaries carry an Authenticode signature, and release files carry build provenance attestations.
  • Two channels: stable by default, preview by choice. Any version can be installed exactly, and the last update can always be rolled back.

More in docs/releasing.md and the changelog.

Security at a glance

  • The dispatcher listens on 127.0.0.1 only. POSTs must be JSON with no Origin header, so a web page cannot drive it.
  • Only the window's own page can send as you, confirm a Fleet proposal, or change a session's settings.
  • A prompt from anywhere else arrives as another session's message, which cannot answer a permission prompt.
  • Remote hosts' tunnels reach a listener that takes hook events and nothing else.
