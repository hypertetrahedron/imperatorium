The window

Every session in one list, grouped by what it needs from you. Select one and see what it actually said and did, without going to its terminal.

imperatorium open          # a chromeless window (Edge --app where there is one)
http://127.0.0.1:8792/     # or open it in any browser

Sessions, grouped by what they need

The sidebar lists every live Claude Code session, local and remote. Each tile says what the session is doing right now, its context use, its pull request, and at a glance how much else it has going: -58 is the minutes until its prompt cache expires, 0/2/1/0 counts subagents, background shells, Monitors and shell processes.

Every state has a colour and a shape, so it reads without colour too:

MarkStateMeans
blue dotworkingin a turn
green ringwaiting on tasksidle, but a shell, Monitor, subagent or wakeup it started is still pending
violet checkcompleteits turn ended and nothing is pending: your turn
amber diamondneeds youblocked on a permission prompt or a question
red crossfailedthe turn failed, and the tile says why

Sessions of the same project gather under one node with a dot per session. Pin, archive, filter, or group by folder instead of by state. n (or alt+N from anywhere) jumps to the next session waiting for you; ctrl+K jumps to any session by name. Reading a waiting session's chat to the end marks it reviewed, which quiets its alerts until it next needs you.

The whole conversation

The chat is read straight from the session's transcript: text, tool calls and their results, thinking, subagent reports and Claude Code's own messages, back through every compaction. Each kind of text can be shown in full, as one line, or hidden. Markdown is rendered by the window itself, so the page loads with no network.

  • Find (ctrl+F) searches all text, tool calls only, or failed results only.
  • Click a file path to open it or its folder.
  • Show Current Prompt pins what the session is working on above the chat.
  • Drafts are kept per session, so switching away mid-sentence loses nothing.

What is running underneath

While a session works, a drawer under the chat follows each running shell, Monitor and subagent live. The tile's Tasks line lists everything the session has going: the tool call in flight, background shells, subagents with the call each is in, scheduled wakeups, the processes its shells started, its MCP servers and any hook failures. Click one to see its output, read a subagent as a chat of its own (with its model, tokens and cost), or end a stray process.

Changes, Activity, Worktrees

Tabs above the conversation show the session's Changes (git status and the diff, where clicking a line leaves a review comment that goes to the session), its Activity (every tool call, what failed and why) and the project's Worktrees. See Parallel sessions.

The Chat Matrix

A second window with a tile for every running session, sized to fill the screen. Each tile holds only Claude's replies and the one step in flight, outlined in its state's colour. Put it on a spare monitor and watch twenty sessions at once; double-click a tile to open that session in the main window. Spare cells become a status tile with the usage meters, model mix and what the open sessions have cost.

Settings, History, Insights

Settings is a window of its own with a search box, for everything you would otherwise edit in config.json. A save checks every value first and keeps the previous file. History searches every past session to resume or fork it; Insights tallies tool failures across projects and what the last 7, 30 or 90 days would cost at API list prices.
