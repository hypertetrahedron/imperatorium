Run twenty Claude Code sessions without hunting for a single window.

Imperatorium is one place to see every Claude Code session on your machine and on the machines you reach over SSH, and one way to send work to any of them. It is a single native binary that runs beside the real Claude Code, not a replacement for it.

The idea

Most ways of working with Claude are built around one conversation: a chat panel in an editor, a desktop app, a terminal tab. That is fine for one session. With ten or twenty running across separate repositories and several virtual desktops, the work stops being "talk to Claude" and becomes "find the window that needs me".

Imperatorium treats finding the window as the symptom, not the problem. If you can send work without visiting a session, and are told the moment one actually wants you, most of the hunting stops being necessary.

What it does, by area

The window

Every session in one list, grouped by what it needs. Its full conversation, live tasks, cost and cache, without switching to its terminal.

Sending work

Dispatch a prompt to any session by name, queue it for the end of a turn, or run slash commands from the window, including the ones that draw pickers.

Parallel sessions and worktrees

New sessions get their own git worktree when another is already working in the folder. See every branch, merge back, open a PR.

Attention and approvals

Permission prompts and questions arrive in the window the moment they happen. Cheap, provably safe asks can be answered for you.

Fleet

Ask "who needs me?" across every session, set watches that alert you, and give any Claude Code session read access to the whole fleet.

Usage and cost

5-hour and weekly meters, prompt-cache countdowns, list-price cost per session and per model, and budget alerts.

Other machines

Sessions on SSH hosts and containers show and take work like local ones, with no daemon and no open port on the host.

Voice, keys and Stream Deck

Local dictation, a global hotkey, a palette, quick phrases, and one Stream Deck key per session.

Install and updates

One command on Windows, Linux or macOS. Signed releases, a preview channel, and one-command rollback.

How it compares

Imperatorium is not an editor, and does not try to be one. It sits beside whatever you already use and works with the sessions Claude Code itself runs. Here is what it adds on top of working with Claude one session at a time:

Principles

  • Real Claude Code, untouched. Sessions are ordinary Claude Code sessions in your terminal. Imperatorium reads their transcripts, talks to them through Claude Code's own hooks, inbox and mod interfaces, and imperatorium uninstall takes its hooks, mod and service back out.
  • Remove prompts, never answers. Auto-approval only answers what is provably cheap. Anything else is exactly the prompt you would have had.
  • A wrong target is worse than a typo. A misheard project name would fire a prompt at the wrong repository, so matching only acts silently when it is certain, and voice fills the prompt, never the project.
  • Nothing on the network by default. The dispatcher listens on 127.0.0.1 only, the window works offline, and phone pushes are off until you turn them on.
