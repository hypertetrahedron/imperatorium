Fleet

One place to ask about every session at once, and to be told when something happens, without an agent that acts on its own.

Fleet is the first row of the session list. Picked, it takes the chat's place: your watches, what waits for you to confirm, what happened recently, and the answers to what you asked.

Ask

"Who needs me?" "What finished while I was away?" "Which session is spending the most?" Ask answers from a snapshot of the fleet: each session's state, how long it has waited, its current step and cost, the permission requests waiting, and the recent events. Sessions in the answer are links that open them.

The answer comes from a claude -p with no tools, no hooks and no MCP servers: it can read the snapshot and nothing else. It uses your plan, so it runs only when you ask, and only from the window.

Watches

Checked by the dispatcher itself every few seconds, with no model in the loop:

  • a session, a project's sessions or any session finishes its work;
  • one waits for you more than N minutes;
  • one costs more than $N.

When a watch comes true it is said in the window and pushed on whichever notification channels you have on.

Proposals, confirmed by you

Ask, or an agent, may propose a watch or an action from a short fixed menu: queue a prompt, stop a turn, compact, open the terminal. Nothing happens until you confirm it in Fleet, and only the window can confirm. A confirmed prompt arrives as another session's message, never as you, so it cannot approve anything. Nothing in Fleet answers a permission request or a question.

Any Claude Code session as the "super agent"

imperatorium mcp is a stdio MCP server over the same data. Register it once and every Claude Code session can see the fleet: status, a session's detail and recent conversation, events, spend and project changes. It can propose watches and actions, and only propose. Text taken from a session's transcript is handed back marked as data, not instructions.

claude mcp add --scope user imperatorium -- "%LOCALAPPDATA%\Programs\imperatorium\imperatorium.exe" mcp
