Usage and cost

How much of your plan is left, what each session is costing, and which contexts are about to get expensive, on every tile.

Plan meters

On a Pro or Max plan the sidebar shows the 5-hour and 7-day windows, each with a tick for how far through the window the clock is. Click the meter for both spend lines and a model mix: how output tokens split between Haiku, Sonnet, Opus and Fable, per window and for the open sessions. A usage-based Team or Enterprise login shows its monthly budget instead, as "$558 of $1000 left". A session on AWS Bedrock, Google Vertex AI, Microsoft Foundry or an API key has no windows, and the meter names the provider instead.

Usage alerts warn at the thresholds you choose (80% and 95% by default) on the notification channels you have on.

The prompt cache, on every tile

A tile's -58 is the minutes until that session's prompt cache expires. Once it has, the tile warns cold 178k, and the chat says what the next prompt will cost to re-read that context. You can see at a glance which session to come back to first, and which one has gone cold.

Cost per session, project and model

Cost and tokens are read from the transcripts, subagents included, and estimated at API list prices, so a restart loses nothing. The status panel under each chat shows the session's cost, context, tokens, model, permission mode, compactions and branch. A subagent opened from the Tasks list shows its own model, tokens and cost.

Insights estimates the last 7, 30 or 90 days by day, project and model, and tallies tool failures across projects. The Chat Matrix's status tile shows what the open sessions have cost and each one's share. A Fleet watch can alert you when a session costs more than a set amount.
