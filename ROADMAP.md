## Deferred
- **Ship hooks as a user-scope plugin** — deferred 2026-11-21 (peer request). The reason it was proposed is mostly met: `imperatorium install` writes the hooks once to the user-level `~/.claude/settings.json`, and the mod already loads as a plugin folder through `CLAUDE_CODE_PLUGIN_DIRS`. What a plugin would still add is marketplace install/update and `${CLAUDE_PLUGIN_DATA}`. Unblocked by: wanting that packaging.
- **Security audit before scripting -p across repos** — deferred 2026-11-21 (peer request) until it becomes relevant. Today the only `claude -p` is Ask's, run in a folder of its own with no tools, MCP or hooks; background dispatch uses `claude --bg` in the project folder, which loads that project's hooks and MCP. Unblocked by: wiring headless dispatch across many repos.
- **Rewind a prompt from the window (Esc Esc)** — 2026-11-16, asked about by the user; recommended as its own piece of work: the mod has no rewind op and `/rewind` opens a terminal menu. Files could come back from Claude Code's per-edit backups or the transcript's edits, the conversation by forking at an earlier message. Unblocked by: the user scoping it.
- **Teammates: idle vs completed** - 2026-11-14. The tile lists active work and "Recently completed"; a teammate (named `Agent` call) does not exit after its task but goes idle and can be messaged again, and `6b7abf2` shows such teammates as a third "idle" state. The user expects subagents to end when their task does. Proposed (not done): a teammate's idle_notification completes its task (into Recently completed with its result), a later SendMessage to it starts a new running task, TaskStop/shutdown marks it stopped. To return to; the tracking fix itself (running from spawn, never filed as finished at once) is live.
- **Host header check (DNS rebinding)** — deferred by the user 2026-11-13. A web page can rebind its own domain to 127.0.0.1 and read the dispatcher's GET answers (no Origin check applies to GETs). Fix: refuse any request whose Host is not `127.0.0.1:<port>` or `localhost:<port>`, in Python and the binary alike. Unblocked whenever the user wants it.

- **herdr integration (dropped)** — 2026-11-24: the user decided not to go forward with any herdr work. Its rows were taken off this table, and its code and docs removed: `herdr/` (mods, layout, tests), `docs/herdr-*.md` and `docs/hc-spike.md`, the hc-hosting refusals in the dispatcher, `/api/dictate` and `/api/open_window` (used only by the herdr mods), the `terminal.host`/`terminal.hc_session` settings and the hooks' `HC_*` fields. The `herdr` branch is untouched.
- **Release process: pre-first-stable checklist** — deferred by the user 2026-11-24; taken up 2026-11-26 as *First stable release (0.4.0)*. Done: everything in `docs/releasing.md` §10 including Windows code signing. Left: a test for `remote add` from Linux, a macOS run (no Mac), and rollback restoring the voice worker. Unblocked by: preparing the first stable release.

- **Phone access as an installable web app with Allow/Deny** (survey item 6, deferred by request 2026-10-15) — needs authentication before the dispatcher listens beyond 127.0.0.1, plus a way in such as Tailscale. Unblocked by choosing that and adding a token check to every route.
- **Shared work queue that respects usage limits** (survey item 7, deferred by request 2026-10-15) — a cross-project backlog that starts background sessions while 5h/7d usage stays under a cap. Unblocked by a decision to take it up; the per-session Queue and the usage meter it would build on exist.
- **Send to several sessions at once, saved prompts** (survey item 8, deferred by request 2026-10-15) — e.g. "commit and push" to every selected session, or compact idle sessions before their cache goes cold. Unblocked by a decision to take it up.

- **Bringing a background *tab* to the front** — a session whose tab is not the one its window is showing cannot be raised into view; focus gets the right window and the tab stays behind. Windows Terminal exposes **no `TabItem` elements to UI Automation** (verified by raw ctypes UIA: `ElementFromHandle` and `FindAll` both succeed and return zero tab items on a two-tab window), and `wt.exe focus-tab` needs a window id and tab index that nothing maps a session to. `WT_SESSION` is a per-tab GUID and is readable by a hook, but nothing turns it into a tab index. Until one of those changes, the honest answer is the note the API already returns, naming the tab title to click.

- **servicehost1** — has never run Claude Code, so there is nothing to poll. developmenthost1 (2026-09-17) and raspberrypi.local (2026-09-24, after updating from 2.1.49, which had no `agents --json`) are done. Unblocked by installing Claude Code there; `python setup_machine.py remote add servicehost1 --install-claude` now does that and the rest.
- **amux adoption** — github.com/mixpeek/amux is the closest existing thing to the desired fleet dashboard (SSE live status, task board, mobile PWA), but it wraps tmux (or `herdr`, whose Windows binary is 0.8.0-preview) and ships only launchd/systemd installers.
